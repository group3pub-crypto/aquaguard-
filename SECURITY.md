# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private "Report a vulnerability"
advisory feature on this repository, or email the maintainers listed in the repository
profile. Include reproduction steps, affected component and impact.

We aim to acknowledge reports within 5 working days and to provide a fix or mitigation
plan within 30 days. This is a research/demo project; there is no bug bounty.

## Scope

Backend API, MQTT broker configuration, dashboard, Telegram bot and deployment files in
this repository. Out of scope: findings requiring physical access to a device, and the
demo credentials generated by `make env` on a developer machine.

## Supported versions

Only the `main` branch is supported. See `docs/security.md` for the security model and
`docs/limitations.md` for known gaps (e.g. no token revocation).
